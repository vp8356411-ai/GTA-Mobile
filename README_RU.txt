GTA WEB MODS MOBILE V2.1 — ПЕРВЫЙ МОБИЛЬНЫЙ ПРОТОТИП

В проект добавлены:
- адаптивное управление касанием;
- поддержка Gamepad API (совместимые Bluetooth/USB-геймпады);
- три режима графики: экономный, высокий, максимальный;
- сохранение выбранного режима графики и настроек гаража;
- manifest и service worker для установки как веб-приложения (PWA) на поддерживаемых браузерах;
- альбомная ориентация и полноэкранный режим.

ЗАПУСК
1. Распакуйте архив.
2. Разместите содержимое папки на HTTPS-хостинге (например, статический веб-хостинг).
3. Откройте адрес игры в Safari на iPhone/iPad или Chrome на Android.
4. На iPhone/iPad: Поделиться → На экран «Домой».
5. На Android: меню браузера → Установить приложение / Добавить на главный экран (если доступно).

ВАЖНО
Это веб-прототип, а не готовый подписанный APK или приложение App Store.
Для 3D-движка Three.js сейчас используется CDN, поэтому первое открытие требует интернета.
Service worker кэширует оболочку приложения, но пока не гарантирует полностью офлайн-работу 3D-движка.
Поддержка Android 6.0/6.0.1 зависит от версии Chrome/WebView и драйвера GPU конкретного телефона; нужна проверка на устройстве.
Gamepad API работает только в браузерах и с контроллерами, которые они распознают. На iOS/iPadOS поддержка зависит от версии системы и браузера.
Для APK понадобится отдельная Android-оболочка, проверка совместимости и подпись. Для App Store — отдельная iOS-сборка и подпись Apple.

Это оригинальный игровой прототип; названия марок используются как ориентиры для типов автомобилей. Машины пока процедурные игровые модели, не точные лицензированные копии.
