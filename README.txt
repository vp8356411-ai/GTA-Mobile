GTA Mobile — установка как приложение (PWA)

1. Загрузите ВСЕ файлы этой папки на любой https-хостинг статических файлов:
   Netlify Drop (app.netlify.com/drop), GitHub Pages, Cloudflare Pages и т.п.
2. Откройте полученную ссылку в браузере телефона или компьютера.
3. Установите:
   - Android (Chrome/Edge/Samsung): меню ⋮ -> «Установить приложение» (или кнопка «📲 Установить» в игре).
   - iPhone/iPad (Safari): «Поделиться» -> «На экран «Домой»».
   - Компьютер (Chrome/Edge): значок установки в адресной строке.
После первого запуска игра работает без интернета.
